## Learned from
A STAR story referenced the project without naming it and without
saying who the work was for. The annotation round: name the project
(Scoolendar), attribute the company, cite concrete scale.

## Rule
Name the project, not "a scheduling app". Attribute the company the
work was for. Cite concrete scale where the records hold one: users,
sessions, tests. Specific evidence reads as lived; generic evidence
reads as filler.

## Rubric
- [ ] Every project named
- [ ] Companies attributed where attribution exists
- [ ] At least one concrete number per major claim where records allow
