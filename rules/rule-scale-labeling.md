## Learned from
The NESA curriculum work entered a draft without a scale label, which
let a side project read as employer-grade. The annotation round
required an explicit label. The delivered 07 letter carries the fixed
form: "my NESA curriculum side project syncs 1,500+ learning outcomes
from 81 syllabus pages monthly via GitHub Actions."

## Rule
Evidence scale must match claim scale. Side projects are labeled as
side projects, personal tools as personal tools, and enterprise work
carries its real numbers. Never let small evidence stand behind a
big-sounding claim.

## Rubric
- [ ] Every piece of evidence carries an honest scale label
- [ ] Side and personal work never reads as employer-grade
- [ ] Enterprise claims cite the real scale from the records
