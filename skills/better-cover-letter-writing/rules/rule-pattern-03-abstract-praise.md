# Pattern 3: Abstract praise → concrete explanation

Read this rule, fix the letter, score the applied level, record
evidence. One rule at a time.

## Rule

Describe what the thing actually is or does instead of praising it.
Ask: "What does this claim actually mean?"

Then describe that instead.

## Before → After

Before:
"My Playwright suite was built to last."

After:
"My Playwright suite was designed as a maintainable test suite rather than a collection of recorded scripts."

## Rubric

Quality: references/quality-rubric.md, minimum acceptable.
Coverage: references/completeness-rubric.md, minimum all.

## Coverage

Sweep for sentences that praise without explaining: built to last,
world class, state of the art, and similar. Every praise word must
be replaced by a concrete description.

## Ask

- What does this claim actually mean?

## Do not

- Do not leave a praise word where a description can stand.
