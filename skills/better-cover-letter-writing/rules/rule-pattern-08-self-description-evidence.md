# Pattern 8: Self-description → evidence

Read this rule, fix the letter, score the applied level, record
evidence. One rule at a time.

## Rule

Avoid claims about personality, mindset, leadership, or impact when an
action can demonstrate the same thing.

## Before → After

Before:
"I brought a quality-first mindset to the team."

After:
"I added automated checks to the areas we tested most often."

## Rubric

Quality: references/quality-rubric.md, minimum acceptable.
Coverage: references/completeness-rubric.md, minimum all.

## Coverage

Sweep for self-descriptions (mindset, passionate, detail-oriented,
team player). Each becomes the action that demonstrates it.

The checker recounts these phrases in the letter:
"mindset", "passionate", "detail-oriented", "team player".
Coverage all requires zero remaining.

## Ask

- Which action demonstrates this trait?

## Do not

- **Always let the user review the evidence claims you added. Each
  self-description turned to evidence must be reviewed by a human.**
- Do not remove content silently. Do not fabricate. Ask if unsure or
  need more information.
